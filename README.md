# نظام إدارة موظفي مجموعة المحيميد القابضة

نظام ويب عربي لإدارة بيانات الموظفين ومتابعة أرصدة الإجازات والاستئذانات بطريقة واضحة وسريعة.

## المزايا

- إضافة الموظف باستخدام الكود، الاسم، الإدارة والفرع.
- إدارات محددة تشمل الإدارة العليا، المالية، الموارد البشرية، الحركة والتشغيل، المستودع والمخازن، وإدارة المشتريات.
- فروع: الرئيسي، حرض، وستون بور.
- رصيد إجازة سنوي قدره 21 يومًا لكل موظف.
- تسجيل إجازة عادية أو طارئة مع الخصم التلقائي من الرصيد.
- رصيد استئذان شهري قدره 4 ساعات لكل موظف، يتجدد تلقائيًا كل شهر.
- منع تجاوز الرصيد المتاح.
- لوحة عربية متجاوبة للجوال والكمبيوتر.
- حفظ دائم للبيانات باستخدام Cloudflare D1 وDrizzle ORM.

## التقنية

- React 19 وNext.js/Vinext
- TypeScript
- Tailwind CSS
- Cloudflare Workers وD1
- Drizzle ORM

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
npm run db:generate
npm run dev
```

## هيكل البيانات

- `employees`: بيانات الموظفين.
- `leave_requests`: الإجازات السنوية ونوعها ومدتها.
- `permissions`: الاستئذانات ومدتها بالدقائق.

## ملاحظات

- الإجازة السنوية تُحسب حسب السنة الميلادية.
- الاستئذان يُحسب لكل شهر بشكل مستقل.
- المستودع خاص ويحتوي على مصدر المشروع للاستخدام الداخلي.
