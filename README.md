# نظام الموارد البشرية — مجموعة المحيميد القابضة

تطبيق عربي مستقل لإدارة الموظفين والإجازات والاستئذانات.

## المزايا

- حساب مدير لإضافة الموظفين وربطهم ببريدهم الإلكتروني.
- حساب خاص لكل موظف يعرض بياناته ورصيده وسجلاته فقط.
- رصيد سنوي قدره 21 يومًا مع إجازة عادية أو طارئة.
- رصيد استئذان شهري قدره 4 ساعات.
- تسجيل الموظف البديل في الإجازات والاستئذانات.
- إدارة الإدارات والفروع من الإعدادات.
- قاعدة بيانات ومصادقة باستخدام Supabase مع سياسات وصول على مستوى الصفوف.

## متغيرات البيئة

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

## التشغيل

```bash
pnpm install
pnpm dev
```

تم تطوير النظام لمجموعة المحيميد القابضة.
